# Как запустить

Нужен Python 3.9+, больше ничего (только стандартная библиотека).

```bash
python report.py --data data --date 10.11.2026                 # отчёт в консоль
python report.py --data data --date 2026-11-10 --csv-dir out   # + два CSV (по работам и по договорам)
python -m unittest discover -s tests -v                        # тесты
```

- `--data` - папка с `contracts.csv`, `works.csv`, `payments.csv` (по умолчанию `data`).
- `--date` - дата отчёта, `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.
- Ошибка в данных (неизвестный договор, сумма с лишними знаками, дубль номера) - программа
  останавливается с кодом 2 и объясняет, что не так. Молча терять платежи она не будет.
- CSV из `--csv-dir` в UTF-8 с BOM (Excel откроет кириллицу), суммы с точкой: `100000.00`.

Файлы: `report.py` - вся программа; `tests/test_report.py` - тесты; `DECISIONS.md` - допущения;
`NOTE_ACCOUNTANT.md` - записка бухгалтеру.
